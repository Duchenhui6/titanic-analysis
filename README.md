# 泰坦尼克号生存率分析

## 项目背景
基于 Kaggle 泰坦尼克号数据集（891 行，12 列），分析性别和舱位等级对乘客生存率的影响。

## 使用工具
- Python (Pandas, Matplotlib, Seaborn)
- Jupyter Notebook

## 主要发现
1. 女性生存率 74.2%，男性仅 18.9%，女性是男性的近 4 倍。
2. 头等舱生存率 63.0%，三等舱仅 24.2%，头等舱是三等舱的 2.6 倍。
3. 性别与舱位叠加后差距放大：头等舱女性生存率 96.8%，三等舱男性仅 13.5%，相差 7 倍。

## 结论
性别是影响生存率的主因，舱位是放大器。"女性 + 头等舱"是生存率最高的组合，"男性 + 三等舱"是最低的组合。
