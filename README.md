# 泰坦尼克号生存预测——机器学习模型对比

## 项目背景

基于 Kaggle 泰坦尼克号数据集（891 行，12 列），分析性别和舱位等级对乘客生存率的影响，并对比逻辑回归、随机森林、XGBoost 三种机器学习模型的预测性能。

## 使用工具

- Python（Pandas、Scikit-learn、XGBoost、Matplotlib、Seaborn）
- Jupyter Notebook

## 主要发现

### 描述性分析
1. 女性生存率 74.2%，男性仅 18.9%，女性是男性的近 4 倍。
2. 头等舱生存率 63.0%，三等舱仅 24.2%，头等舱是三等舱的 2.6 倍。
3. 性别与舱位叠加后差距放大：头等舱女性生存率 96.8%，三等舱男性仅 13.5%。

### 机器学习建模
| 模型 | 准确率 | 生还 F1 |
|------|--------|---------|
| 逻辑回归 | 81.06% | 0.76 |
| 随机森林（默认） | 82.12% | 0.78 |
| XGBoost（调参后） | 80.45% | 0.74 |

**最终选择随机森林**：在小数据集上，随机森林的“并行投票”机制比 XGBoost 的“串行纠错”更稳健。

**特征重要性**：Fare、Sex、Age 是预测生存率的核心特征。
